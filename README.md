SABLE LINE — a round-based tactical FPS in three.js: 4v4 on the Kestrel Yard map, bomb plant/defuse, CS-style economy with a buy menu, five weapons, and waypoint bots that see, hear, and shoot back. First to 5 rounds takes the match.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and click to play. WASD moves, mouse aims, click fires, R reloads, B opens the buy menu, G throws a grenade, E plants/defuses, Ctrl crouches, Space jumps.
